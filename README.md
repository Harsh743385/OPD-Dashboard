# OPD-Dashboard
## JIKA Hospital & Research Institute — NABH-Accredited Digital OPD Command Center

A modern, enterprise healthcare SaaS dashboard designed for NABH-accredited and NABH-preparing multi-specialty hospitals.

---

### Features & Capabilities

- **Executive OPD Command Center:** Real-time footfall counters, live 8-stage patient flow pipeline, peak-hour heatmaps, and doctor/specialty performance breakdowns.
- **NABH 5th Edition Full Compliance:** Detailed tracking across all 10 core chapters (**AAC, COP, MOM, PRE, HIC, PSQ, ROM, FMS, HRM, IMS**), 131 Standards, and 695 Objective Elements with interactive CAPA & Document Control registers.
- **Diagnostics & Nursing Tracking:** Real-time visibility into Laboratory and Radiology queues, critical value alerts, overdue countdowns, nurse triage assessments, and emergency bed occupancy.
- **Zero Harm & Patient Safety (PSQ):** Zero harm metric monitoring (0 ID errors, 0 falls, 0 needle-stick injuries, 0 sentinel events) and Bio-Medical Waste (BMW Rules 2016) 4-color segregation tracking.
- **Infection Prevention & Control (HIC):** WHO 5 Moments of Hand Hygiene compliance audits, environmental water/air settle plate tests, and 3-shift clinic disinfection rosters.
- **Patient Experience & Grievance Redressal:** Net Promoter Score (NPS +71), CSAT (4.68 / 5.0), multichannel feedback capture (Kiosk, WhatsApp, QR, Helpdesk), and grievance escalation matrix.
- **Digital Health & AI Engine:** ABDM M1/M2/M3 certification, ABHA linkage, AI surge forecasting, live digital queue board with speech PA announcements, and cashless payment mix.
- **Export & Reporting:** 1-Click certified PDF/Print audit dossiers and CSV data export.

---

### Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS (Modern Enterprise Healthcare Palette)
- **Icons:** Lucide React
- **Data Visualization:** Recharts
- **Voice PA Calling:** Web Speech API

### Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Harsh743385/OPD-Dashboard.git
   cd OPD-Dashboard
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
